# Known limits and deferred work

- No physical board was programmed or measured. OOC implementation is FPGA-fabric evidence, not physical hardware operation.
- The only supplied XDC timing basis is a 10 ns internal clock. Board pins, configuration voltage and external I/O delays are unverified. `board_pins_TEMPLATE.xdc` is a template, not usable board constraints.
- SDF post-route timing simulation failed its demo status/count assertion at 20,150 ns. SDF annotation success and process exit status do not make that a PASS. The generated checkpoint/netlist/SDF bytes were not recovered; exact re-execution is unavailable from this release.
- Supplemental functional-netlist PASS at 530 ns is supported by an original console extract, not a new run here.
- Four-router, single-flit, deterministic XY design; no adaptive routing, virtual channels, multi-flit packet protocol or CPU/cache implementation.
- The registered output arbiter has a bubble between accepts. Full-FIFO simultaneous push/pop accepts only the pop; sources retry. These are documented controller choices, not hidden packet drops.
- The 93 experiments use finite windows and fixed seeds. Minimum/maximum whiskers are not statistical confidence intervals. No fair bus baseline, physical power result or broad scalability study is supplied.
- The dashboard replays saved records. An arbitrary imported CSV does not prove its claimed tool provenance.
- A manuscript is included as a draft. Faculty signatures, plagiarism clearance, institutional endorsement and publication acceptance are not generated by this repository.
- Team credit is separate from commit-derived GitHub contributor statistics. No fabricated development history is added to change that graph.

Potential research extensions include bubble-free arbitration, virtual channels, larger meshes, longer trials and controlled baseline comparisons. They are proposals, not implemented release features.
