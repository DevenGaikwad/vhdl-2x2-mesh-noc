# Current requirements and decisions

The repository publishes an implemented four-router educational VHDL-2008 mesh. It preserves the exact original source and evidence contracts while adding current documentation and a reviewed frontend dependency patch. See [architecture](docs/architecture.md), [verification](docs/verification.md) and [provenance](docs/provenance.md).

Private repository by default. No hosted dashboard or physical-board claim. No invented pins, FPGA voltages, signatures, authorship history or license choice. Original 93-run records are immutable. Later GUI core observations stay separate from archived reports. SDF timing simulation remains unresolved/deferred. All three report team members receive profile-linked credits.
