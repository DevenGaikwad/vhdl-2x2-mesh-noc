## Authoritative technical facts

The baseline is a VHDL-2008 four-router, 32-bit, single-flit mesh. FPGA implementation is a target flow; physical FPGA operation has not been demonstrated.

| Router index | Name | Coordinates | Endpoint label |
| --- | --- | --- | --- |
| 0 | R00 | X=0, Y=0 | CPU 1 traffic model |
| 1 | R01 | X=1, Y=0 | Memory traffic model |
| 2 | R10 | X=0, Y=1 | CPU 2 traffic model |
| 3 | R11 | X=1, Y=1 | AI traffic model |

Index = X + 2Y. X increases east and Y south. Neighbor pairs are 0–1, 0–2, 1–3 and 2–3, forming eight separate directed channels. Each channel has 32-bit data, forward valid and reverse ready. Four Local interfaces support injection and ejection.

There are five logical ports: N=0, S=1, E=2, W=3, L=4. Each corner has only three active input/output ports. There are twelve active input FIFOs and twelve independent active output arbiters in the mesh. Mask bit order L W E S N:

| Router | Mask |
| --- | --- |
| R00 | 10110 |
| R01 | 11010 |
| R10 | 10101 |
| R11 | 11001 |

The reference FIFO depth is 4. Depths 2 and 8 are controlled comparisons. Logical packet storage is 12 × depth × 32 bits: 768, 1536 and 3072 bits. These are logical capacities, not synthesized LUT/FF/BRAM measurements.

| Packet bits | Field | Meaning |
| --- | --- | --- |
| 31 | Marker | 1 for a legal packet; independent of external valid |
| 30:29 | Type | DATA = 00 |
| 28:27 | Source | X at 28, Y at 27 |
| 26:25 | Destination | X at 26, Y at 25 |
| 24:21 | ID | Four bits, wrapping at 16 |
| 20:19 | Priority | Reserved and ignored by round robin |
| 18:0 | Payload | 19 bits |

Normal acceptance is a rising edge with rst=0, valid=1 and ready=1. A producer holds valid and the complete word through a stall and does not wait for ready before asserting valid. Reset is synchronous active-high, overrides normal transfers, clears queue pointers/counts and grants, and explicitly flushes previously accepted pending traffic.

FIFO input ready derives from registered occupancy. An empty FIFO has no bypass. At intermediate occupancy simultaneous push and pop can both succeed. A full FIFO accepts a pop but refuses a simultaneous push; the producer retries next cycle. Pointer wrap supports non-power-of-two depths. Unsupported packet encodings trigger simulation assertions; the synthesized baseline does not implement a packet-type rejection engine.

Routing compares X first, then Y, then selects Local. R00 to R11 follows 0 → 1 → 3. R10 to R01 follows 2 → 3 → 1. Legal dimension-order paths have an acyclic channel-dependency argument, but this does not guarantee finite progress when sinks refuse forever.

Each occupied head requests one output. Each active output has a FREE/HELD controller and registered one-hot round-robin grant. HELD retains selection/data until acceptance. Acceptance pops the selected input once, clears the grant and advances rotating priority to one past the winner. The crossbar muxes retained FIFO heads; no extra output packet register is required. Independent inputs can transfer concurrently to different outputs.

After an acceptance, one arbitration bubble precedes the next possible transfer. The individual output service ceiling is 0.5 flits/cycle. Empty-network exclusive latencies are Local=2, one hop=4 and two hops=6 cycles. Aggregate throughput can exceed 0.5 because separate outputs operate in parallel.

The project contains 11 RTL files and 6 testbenches. Four FIFO tests (depths 1, 3, 4, 8), one route test, one arbiter test, four corner-router tests, one finite-demo test and three directed mesh-depth tests give 14 completed supplemental GHDL 4.1.0 configurations. All passed. All 16 source/destination pairs and all 8 directed channels were exercised. Tests cover all active outputs under three-input contention, nonconflicting concurrency, FIFO limits, stalls, full-word integrity, reset and stream order. A persistent arbiter requester is bounded by five successful grants in the five-input test; stalled wall-clock cycles are excluded from this bound.

The accepted-event scoreboard stores the full word, injection edge, current location, shortest-hop count and source/destination stream sequence. Link accepts must follow XY and location; deliveries must match the full word, destination, pending identity, hop count and stream order. The bounded tests use unique payload identities because a four-bit packet ID wraps. Independent sources have no global ordering contract. Whole-run conservation is accepted = delivered + reset discards + outstanding.

## Controlled experiment evidence

There are 93 actual RTL runs: three depths × 31 configurations. Each depth contains four deterministic cases; all-to-all and hotspot at four gates × three seeds each; three sink-stall seed cases. Depth 4 was verified first. Gates are 0.10, 0.25, 0.50, 0.90. Seeds are 101, 202, 303 using xorshift32. Each run has 100 warm-up cycles, 1000 measurement cycles, a drain bound of 5000 cycles and a 30,000-edge watchdog.

Workloads:

- No load: source 0 to 3 once every 40 cycles.
- Disjoint: sources 0 and 1 to 2 and 3 every four cycles.
- All-to-all: free-source gated generation, PRNG destination including Local.
- Hotspot: free-source gated generation, all destinations node 1.
- Burst: first 20 of every 100 cycles, destination=(source+3) mod 4.
- Sustained: every source re-offers to 1 after prior acceptance.
- Sink stall: gate 0.50 to (source+3) mod 4, sinks refuse for the first 60 of every 160 cycles.

Sources hold one pending request, so generation gate is conditional on an available slot. PRNG advances every cycle even for blocked sources. Matched seeds and schedules across depths do not guarantee the same accepted transaction population. Do not plot gate as if it were a guaranteed open-loop injection rate.

Latency = delivery acceptance edge − injection acceptance edge. The latency cohort consists of measurement-window injections followed through drain. P95 uses nearest rank. Throughput = accepted deliveries during the measurement window / 1000. Accepted and delivered window rates can differ at warm-up/drain boundaries. FIFO occupancy uses pre-edge samples of twelve active inputs. Stalls are output port-cycles. Source Jain index uses four source delivery counts and is descriptive; it is not an arbiter fairness proof.

All 93 runs drained: 82,523 accepted = 82,523 delivered, zero reset discards and zero outstanding. No unexplained loss, duplicate, misroute or source/destination stream reorder was observed under the supplied finite assertions.
